## Aufbau der Einträge

Jeder Eintrag im Algodex folgt einem einheitlichen Schema:

1. **Intuition & Kernidee:** Worum geht es bildhaft, bevor Code geschrieben wird?
2. **Saubere Implementierung:** Nachvollziehbarer Code mit aussagekräftigen Kommentaren und Type Hints.
3. **Komplexitätsanalyse:** Aufschlüsselung von Zeit- ($O(T)$) und Speicherbedarf ($O(S)$).
4. **Edge Cases & Fallstricke:** Typische Randfälle und Stolpersteine.
